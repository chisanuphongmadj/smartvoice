# SmartVoice — คู่มือการใช้งาน

> **สำหรับ:** ผู้ดูแล Call Center, QA, Supervisor
> **เวอร์ชัน:** 1.0

---

## 🎯 SmartVoice ช่วยอะไรได้บ้าง?

1. **ถอดเสียง** การโทรภาษาไทยเป็นข้อความอัตโนมัติ
2. **แยกผู้พูด** ว่าเป็นพนักงาน (Agent) หรือลูกค้า
3. **วิเคราะห์** ด้วย AI:
   - สรุปบทสนทนา
   - หัวข้อปัญหา (Topic/Intent)
   - อารมณ์ลูกค้า (Sentiment)
   - คะแนนพนักงาน (Politeness + Problem Solving)
   - ความผิดปกติที่ต้องเตือน (Anomaly)
4. **จัดกลุ่มเคส** ลูกค้าคนเดียวกันเรื่องเดียวกัน → รวมสายเป็น Case เดียว
5. **ค้นหา** ลูกค้า / warranty ได้ทันที

## 📤 Workflow หลัก: อัปโหลดและวิเคราะห์สาย

### ขั้น 1: อัปโหลดไฟล์เสียง

1. กด **📤 Admin** ด้านซ้าย
2. ลากไฟล์ `.wav` หรือ `.mp3` ลงในกล่อง หรือกด **Browse files**
3. ระบบจะ:
   - ตรวจไฟล์ไม่ซ้ำ (hash-based duplicate detection)
   - **ดึงเบอร์โทรจากชื่อไฟล์อัตโนมัติ** ถ้ามี (เช่น `20251225-0631451550-Inbound.wav`)
   - **เชื่อมกับลูกค้าอัตโนมัติ** ถ้าเบอร์อยู่ในระบบ
   - แสดงข้อความเขียว ✅ = อัปโหลดสำเร็จ

> **💡 Tip:** ชื่อไฟล์ที่มีเบอร์ 10 หลักขึ้นต้นด้วย 0 จะช่วยให้ระบบเชื่อมลูกค้าได้เลย

### ขั้น 2: สั่ง Process

มี 2 วิธี:

**วิธี A — Process ทั้งหมดที่ pending** (แนะนำ)
- กด **▶ Process All Pending** (ปุ่มสีฟ้าด้านบน)
- ระบบจะเริ่มประมวลผลทีละไฟล์ใน background

**วิธี B — Process ทีละไฟล์**
- ขยาย card ของไฟล์ที่ต้องการ
- กด **▶ Process** ด้านขวา

### ขั้น 3: รอผล

- แต่ละไฟล์ใช้เวลา **~1-3 นาที** (ขึ้นกับความยาวสาย + GPU)
- สถานะจะเปลี่ยน: `UPLOADED` → `PROCESSING` → `DONE`
- มี progress bar บอกขั้นตอนปัจจุบัน (🎙 ถอดเสียง → 🧹 แก้ไข → 🗣️ แยก Speaker → 🤖 วิเคราะห์ → 📂 จัดเคส)

### ขั้น 4: ดูผลใน Admin

ขยาย card ของไฟล์ที่ DONE จะเห็น:

- **ข้อมูลลูกค้า & รับประกัน** — ลูกค้าที่ system เชื่อมให้อัตโนมัติ (🤖 Auto) หรือ manual (✋)
- **เคส** — สายนี้ถูกจัดเข้าเคสไหน, มีสายอื่นใน case เดียวกันไหม, เปลี่ยนสถานะเคสได้
- **Tagged Transcript** — ข้อความเต็ม พร้อม speaker tag

## 📊 Dashboard: ดูภาพรวมและวิเคราะห์

### ส่วนบนสุด — KPI

- จำนวนสายทั้งหมด
- Positive / Neutral / Negative (แยกตาม sentiment)

### กราฟหลัก

| กราฟ | ความหมาย |
|------|----------|
| **Sentiment Distribution** | สัดส่วนอารมณ์ลูกค้า |
| **Topic / Intent Distribution** | หัวข้อหลักที่ลูกค้าโทรมาคุย |
| **Issue Keywords** | คำที่ถูกพูดถึงบ่อย (ปัญหา) |
| **Brand Mentions** | แบรนด์สินค้าที่ลูกค้าพูดถึง |
| **Platform Mentions** | แพลตฟอร์ม (Shopee, Lazada, etc.) |

### Anomaly Detection

กล่องด้านขวา — แสดงสายที่ระบบเตือนว่า **ผิดปกติ** พร้อมเหตุผลและระดับความรุนแรง:
- 🔴 High — ต้องรีบตรวจ (ลูกค้าขู่ฟ้อง, สินค้าเสียหายรุนแรง)
- 🟡 Medium — ควรติดตาม
- 🟢 Low — ปกติเล็กน้อย

### Top 3 Issues

สายที่เป็น Negative หรือ Anomaly — เอามาแยก top 3 topic

### Agent Performance

ตารางประเมินพนักงานแต่ละสาย:
- **Politeness** — ความสุภาพ (1-5)
- **Problem Solving** — แก้ปัญหา (1-5)
- **Score** — คะแนนรวม (2-10)
- **Next Action** — เรื่องที่ต้องติดตาม
- **ผู้รับผิดชอบ** — ใครต้องดำเนินการต่อ (Agent / หัวหน้าทีม / ฝ่ายบัญชี / ฝ่าย QC / ฝ่ายจัดส่ง ฯลฯ)

### Filters

- กด **🔍 Filters** เพื่อกรองข้อมูลตามช่วงวันที่, topic, sentiment

## 📂 Workflow จัดการเคส (สำหรับ Supervisor)

เคส = กลุ่มการโทรของลูกค้าคนเดียวกัน เรื่องเดียวกัน

**ตัวอย่าง:** ลูกค้าโทรเข้ามาเรื่องที่นอนชำรุด 3 ครั้ง → รวมเป็นเคสเดียว

### สถานะเคส

| สถานะ | ความหมาย |
|-------|----------|
| 🟢 **เปิด (open)** | สร้างใหม่ ยังไม่มีการ follow |
| 🟡 **ติดตาม (follow_up)** | มีสายตามมาอีก (LLM auto-assign) |
| 🔴 **ปิด (closed)** | เคสจบแล้ว |

### วิธีเปลี่ยนสถานะ / แก้หัวข้อเคส

1. ไปที่หน้า **📤 Admin**
2. ขยาย card สายที่ต้องการ
3. กดขยาย **📂 เคส** ใต้ Tagged Transcript
4. เปลี่ยนสถานะ หรือแก้หัวข้อเคส → กด **💾 อัปเดท**

## ❓ FAQ

### Q: ระบบ process ช้า ทำยังไง?
A: ตรวจว่ามี GPU + CUDA พร้อมใช้ — ดู `SETUP.md` §4. ถ้าไม่มี GPU ใช้เวลา 5-10 นาที/สาย

### Q: ทำไม sentiment ผลไม่ตรง?
A: LLM อาจพลาดในบางเคส — ใช้ **🔄 Re-process** เพื่อลองใหม่ หรือปรับ prompt ใน `smartvoice/prompts.py`

### Q: เบอร์โทรในชื่อไฟล์ไม่ถูกดึงมา?
A: ต้องเป็นรูปแบบ **10 หลักขึ้นต้นด้วย 0** — เช่น `...-0812345678-...` (ไม่ใช่ `081-234-5678`)

### Q: ลูกค้าไม่อยู่ในระบบ จะเพิ่มได้ไหม?
A: ปัจจุบันเพิ่มผ่าน `scripts/seed_mock_data.py` หรือใส่ตรงใน DB — ในเวอร์ชันหน้าจะมีฟอร์ม UI

### Q: มี error พัง debug ยังไง?
A: ดูไฟล์ `data/logs/smartvoice.log` — มี stack trace ครบ
